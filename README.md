# PokeRock

PokeRock is a interactive pokemon explorer built using HTML,CSS and JavaScript. it uses the PokeAPI to fetch Pokemon data and display it in a responsive card bsed interface.

# Demo

[** PokeRock →**](https://udayprakash999.github.io/pokerock/)

# Features

- search Pokemon
- Pagination
- fetch pokemon data from the Poke API
- scroll interaction
- used data to form cards dynamically using DOM
- prev and next btn
